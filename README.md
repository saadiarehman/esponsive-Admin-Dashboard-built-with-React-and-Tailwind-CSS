# React Tailwind Admin Dashboard

A responsive admin dashboard UI built with React and Tailwind CSS.

## Features

- Responsive sidebar
- Responsive navbar
- Dashboard cards
- Statistics section
- Responsive layout
- Hover effects
- Modern Tailwind CSS design

## Technologies

- React
- Tailwind CSS
- Vite
- JavaScript/TypeScript
